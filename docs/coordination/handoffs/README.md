# Handoffs

Canal assíncrono entre agentes. Um arquivo por entrega, pedido ou bloqueio. Nunca editar handoff de outro agente; responda com novo arquivo.

Nome: `AAAA-MM-DD-agente-NN-<tema>.md` (ex.: `2026-11-14-agente-02-conector-pncp.md`).
Tipos: `entrega` · `pedido` (mudança em área de outro agente ou em contrato) · `bloqueio` · `resposta`.
Use `TEMPLATE.md`. Entrega sem evidência verificável (comando + saída, PR, teste) não é aceita.
